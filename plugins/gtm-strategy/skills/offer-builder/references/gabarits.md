## Partie C : l'offre
```
## L'offre en bref
En une phrase : [la meilleure phrase]
Pour qui : [ICP précis]
Douleur traitée : [la première]
Résultat principal : [ce que le prospect obtient]
Preuve : [chiffre ou preuve sociale réelle]

## Niveau 1 : la phrase (3 versions)
- Résultat + vitesse : "[verbe] [résultat] en [délai]"
- Résultat + effort évité : "[verbe] [résultat] sans [ce qu'ils détestent]"
- Transformation : "Passer de [mauvais état] à [bon état]"
Règles : ouvrir sur le résultat, des chiffres précis, crédible, relié à leur douleur.

## Niveau 2 : la proposition de valeur
"On aide [ICP] à [résultat] grâce à [approche], pour [impact]."
- Qui : [ICP précis, pas "les entreprises"]
- Ce qu'ils obtiennent : [résultat mesurable]
- Comment : [approche propre, en une phrase]
- Pourquoi ça compte : [l'impact business]

## Niveau 3 : l'offre complète
Problème → Aggravation → Solution → Résultat → Preuve

## Par canal
Objets d'email (3 options, 5 à 7 mots) : [...]
Ouverture d'email (2 phrases) : [constat d'une douleur + résultat]
LinkedIn (80 caractères) : [question ou constat sur le résultat]

## Erreurs à éviter
- [erreur précise tirée de ce que l'entreprise dit aujourd'hui]
- [une autre]
```

## Questions à poser pour le temps C (si l'info manque)
Ce que vous faites, pour qui, quel problème ça règle, ce qui se passe après l'usage (le résultat), ce qui se passe si on n'achète pas (coût de l'inaction), résultats ou chiffres clients.
