# _TEMPLATE — format d'un bloc de bible

## En-tête (obligatoire)
```
# 0X — <Titre du bloc>
> MAJ : YYYY-MM-DD · par : <qui> · confiance globale : 🟢/🟡/🔴
```

## Convention de confiance (sur toute info sensible ou chiffrée)
- 🟢 **vérifié** — confirmé par le client ou une source primaire (dater la source).
- 🟡 **probable** — déduit/estimé, cohérent mais non confirmé.
- 🔴 **à confirmer** — hypothèse, on ne construit rien de critique dessus.

## Règles d'écriture
- Court, factuel, listes > paragraphes. Un fait = une ligne.
- Chiffre ou claim → source dans `docs/sources.md` (référencée, pas copiée).
- Ce qui périme vite (état, campagnes) vit dans README *État & priorités* ou `08`, pas ici.
